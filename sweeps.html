One family, one sentence, only the argument changes. Each row is the same command with a different value; the clips were produced from the sentences alone (parser, grounder, device logic, bake, render), nothing was authored per value. Under each clip: the value, what the command changed (angle, display, amount) and the sentence as issued.

turn the dial to time

Any m:ss (or '45 seconds', 'three and a half minutes') maps to a dial angle at 100 s per radian; the Samsung-style panel shows it in 5 s steps, so 1:37 reads 1:35.

view

turn the timer knob to time

The mechanical timer takes any time to the second, up to the knob's end stop (8:43).

view

turn the front-left knob to level n

Integer levels 0–9 at 30° per level; the zone glows while the level is above 0 (level 9 reaches the knob's end stop).

view

set the oven to temperature

A keypad setting: the device logic plans Bake then + presses in 25 °F steps from 350 (0, 2 and 4 presses here).

view

turn the grind amount dial to mass

A continuous dose 8–22 g (18 g at rest): the angle is linear in grams.

view

pour volume of milk from the milk carton into the jug

The ledger moves the asked volume (the jug holds 350 mL); the pour lasts longer for more milk.

view

press the Start key count

+30s / Start from idle starts a 0:30 cycle and adds 30 s per further press.
